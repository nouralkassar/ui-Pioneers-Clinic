Design a professional interactive web dashboard prototype for a Medical Center Management System.

The system has three web roles:
1. Super Doctor (Admin Doctor)
2. Doctor
3. Secretary

The design should be modern, clean, and medical-style UI with clear hierarchy and easy navigation.

Color palette:
- White (#FFFFFF)
- Dark navy (#1C2235)
- Medical blue (#2F6FA3)
- Secondary blue (#1E5A8A)

Use these colors professionally with white backgrounds, blue highlights, and dark navigation.

Layout Requirements:

Create a responsive web dashboard with:
- Left sidebar navigation
- Top header with notifications and profile switch
- Main content workspace
- Role switcher (Doctor / Super Doctor)

Include interactive navigation between pages.

--------------------------------

Main Web Pages

Login Page
- Email
- Password
- OTP verification
- Role based access (Doctor / Super Doctor / Secretary)

Dashboard
- Overview cards
- Notifications
- Upcoming appointments
- Recent patients

1. My Patients

- Patient profile

- Select chemotherapy protocol
- Adjust doses
- Modify treatment schedule

5. Medical Analytics
- Patient progress charts
- Vital results visualization
- Treatment response graphs

6. Alerts
- Drug interaction warnings
- Toxicity alerts
- Medical notifications

- View all doctors

4. System Notifications
