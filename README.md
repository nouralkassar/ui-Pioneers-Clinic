# Al-Rawad Clinic — Frontend UI

A React-based frontend UI prototype for a clinic management system, focused on clean design, reusable components, and intuitive healthcare workflows.

## Technologies

- React.js
- TypeScript
- Vite
- Tailwind CSS
- Material UI
- Lucide React

## Project Overview

This repository showcases frontend interface development for a healthcare management application.

It focuses on creating modern layouts and reusable UI components that can support administrative and clinical workflows.

## Getting Started

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Start the development server using `npm run dev`.

## Project Scope

This repository showcases a frontend UI prototype. It should not be confused with the complete clinic management system and its backend services.
